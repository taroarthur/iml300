Vibe Coding

Week 1: Fibonacci MIDI Generator

This script uses Python's MIDI API to generate some notes based on the Fiboquadratic number sequence. These values were computed manually using a formula I obtained from a research project. Essentially, the digits 0-9 are mapped to a particular note, (C, D, E, F, G, A, B), and randomly placed on higher/lower octaves. Users can input a particular tempo that they want to have the sequence play before downloading the file - you'll need a DAW to open the file!

Week 2: Worst Volume UX Gallery

Inspired by the User Experience article, I prompted AI to create a gallery of the most terrible volume slider UX it could conjure up. It's interesting to see the very AI user interface and the frustration that can be created by bad UX design & how it can be weaponised to an extent to purposefully aggravate us (sort of going off of the 'Desktopisation of War' idea). It's also funny to reference a real-life competition a group of developers on Reddit had several years ago, and how much more creative the designs were when humans made them!

Week 5: Mirrored Webcam & Pixel Sampler

Based on the Sydette Harry writing, I vibe coded a p5-adapted version of my Identity Expression assignment from IML 295, which explores the ways technology/code works as a method of racial surveillance. It was interesting to see how AI (ChatGPT) adapted something originally made for Touchdesigner into p5 – the UI was surprisingly clean, compared to my previous HTML vibe coding exercises.

Week 6: Computer Music — A Very Small Website

Having seen Maya Man's website + the history of the internet lecture, I was intrigued by HTML as an aesthetic and the use of websites to document history

Week 7: Image Edit

Inspired by Chia Amisola's "Engine.lol", I created a website that allows users to apply low-res effects to images and export them as pop-up windows. The goal was to effectively prompt AI to more or less 'mimic' a certain aesthetic from screenshot references, rather than letting it make its own. The design principles/aesthetic mirrors Amisola's article on "Making space for handmade web".

Week 8: Waiting in a Line — Interactive Score

W8 Vibecoding exercise based on Christine Sun Kim's TED talk & her graphic scores. The scores mirror a sense of ‘deafening silence’, where the p5 sound library generates 20 hz pulses, creating a bodily sensation/disruption although the ears can’t perceive that low frequency.

Week 9: Space Waste Explorer

I was inspired by Xin Liu's website + artist statement – "Liu’s practice examines the entropic aftermath of technological and scientific aspiration, foregrounding exhaust as a generative state: rocket fragments falling back to Earth; cryogenic vessels suspending organic matter; genomic code rendered as unreadable scripture; plastics dissolving under enzymatic digestion; satellites logging their own obsolescence." => I opted for more of a researched/scientific take on this through interactive web design. It's interesting to see how AI understands a parameter like 'research' before building.

Week 13: Image Edit

I edited my vibe code experiment from w6 and hand-coded new design aesthetics that weren't dictated by AI. My choices aim to humanise the design more by making the text larger and more accessible, adding a brighter and friendlier colour scheme, as well as guide the eye with subtle hover effects.
